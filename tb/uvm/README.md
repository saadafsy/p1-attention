# tb/uvm: a UVM environment for matmul_tile

Added 2026-09-19 (target-scores change 1). A second verification
environment for ONE module, beside the cocotb suite that remains the
regression for every module and the primary golden-model check (README:
cocotb for the full design, UVM for matmul_tile).

## What is here

| File | Role |
|------|------|
| tile_if.sv | interface with driver/monitor clocking blocks and an edge counter |
| tile_seq_item.sv | one edge of stimulus: rand rst/en/clr, rand Q1.6 q[4]/k[4] with edge-weighted constraints; golden and observed acc |
| tile_sequence.sv | tile_replay_sequence (drives a Python-generated golden file) and tile_random_sequence (SV constrained-random dot products, bubbles, clears, resets); tile_sequencer typedef |
| tile_driver.sv | one item per edge, publishes driven items for the scoreboard |
| tile_monitor.sv | observed transaction per edge (stimulus + the acc it produced), optional trace file |
| tile_agent.sv, tile_env.sv | the usual wiring |
| tile_scoreboard.sv | pairs driven and observed edges by edge number; compares all 16 accumulators against the golden columns (replay test) or checks the control contract only (random test); uvm_fatal on any error |
| tile_coverage.sv | covergroups: operand signs and their cross, Q1.6 magnitude classes crossed with lane, clr/en control rows, dot-product length incl. the full-16 and beyond-16 bins, hold transitions, SACC magnitude classes up to the D=16 extremum crossed with lane |
| tile_assertions.sv | SVA bound to mac_unit (five contract rows, no-overflow as a bound on the exact next value, no hidden latency) and to matmul_tile (bus-wide reset/clear/hold) |
| tb_top.sv | interface + DUT + uvm_config_db handoff + run_test; $fatal if any UVM error was reported |
| tile_uvm_pkg.sv | the package that includes the class files |
| scripts/run_xsim.sh, scripts/merge_coverage.sh | Vivado xsim compile/run and xcrg merge |
| vectors/tile_seed_17.txt | one golden vector file, generated by scripts/gen_tile_uvm_vectors.py (regenerable: `make vectors SEED=17`) |

## The one design rule

No SystemVerilog reference model of the MAC exists here, on purpose: the
project's bit-exact reference is model/attn.py and the mirror derived from
it. Golden values reach the environment two ways, both from Python:

1. Replay test: scripts/gen_tile_uvm_vectors.py --emit writes constrained-
   random stimulus AND the mirror's expected acc_flat after every edge; the
   scoreboard compares in-sim, every accumulator, every edge.
2. Random test: the SV constraints generate the stimulus; the monitor
   writes the observed trace; scripts/gen_tile_uvm_vectors.py --check
   recomputes the expected values over that trace after the run. In-sim
   the scoreboard still checks the control contract (reset, clear, hold).

Two bins the brief asked for are absent by design: "saturation hit" and
"round-half-up tie". matmul_tile has neither a saturation nor a rounding
site (exact integer accumulation, docs/uarch.md 8.1); those corners live at
attention_top's score conversion and are in tb/attention_top's functional
model. Covering them here would be coverage of something the DUT does not do.

## Simulator

Vivado xsim (free, ships UVM 1.2, the same install the FPGA phase needs).
Verify the compile switches with `make -C tb/uvm smoke` first; the
coverage-database switches of xsim and the merge capability of xcrg have
moved between releases, and scripts/merge_coverage.sh fails loudly rather
than summing per-seed percentages if merging is unavailable.

## The evidence gate (all four, or nothing is claimable)

```
source /opt/Xilinx/Vivado/<ver>/settings64.sh
make -C tb/uvm smoke          # compiles, runs, writes a coverage database
make -C tb/uvm gate UVM_SEEDS=10
```

`gate` = `regress` (10 seeds x replay + random, merged coverage report)
followed by `bug-proof` (rtl/mac_unit.sv compiled with +define+INJECT_BUG,
a load row that ignores clr; the replay test MUST fail and xsim MUST exit
nonzero, or the target itself fails). Record the Vivado version, the
merged coverage percentages and the bug-proof log lines in the EVIDENCE.md
row; only then: "Built a UVM verification environment (agent, driver,
monitor, scoreboard, covergroups, SVA) for a fixed-point MAC tile,
self-checking against a bit-exact Python reference model, with
constrained-random stimulus and a seeded multi-run regression."
